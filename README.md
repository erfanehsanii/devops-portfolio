# DevOps Portfolio

A personal portfolio for **Erfan Ehsani**, focused on DevOps, cloud infrastructure, observability, and platform engineering.

Built with Next.js, TypeScript, and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000).

## Customize

All portfolio content is centralized in [`src/data/portfolio.ts`](src/data/portfolio.ts): profile copy, skills, work history, projects, certifications, and social links. Update that one file to tailor the site without changing the page layout.

## Quality checks

```bash
npm run lint
npm run build
```
